# Changelog

All notable changes are documented here. This project follows semantic versioning.

## 0.1.0 — Unreleased

### Added

- Multi-project local workspace with shared measurement profiles and slopers
- Interactive measurement-driven bodice preview and drafting tutorial
- First-class pattern versions, muslins, fit sessions, materials, notions, references, and construction tasks
- IndexedDB autosave with visible save state and first-run sample/blank choice
- Validated versioned JSON backup and all-or-nothing restoration
- Project and workspace Markdown exports plus CSV views
- Optional user-authorized local folder copies
- Static production build, offline worker, Docker and native development workflows
- Synthetic sample data, responsive editorial interface, and release documentation

### Security and privacy

- Removed hosted data services, account integration, private image defaults, and runtime server routes
- Added strict container ignore rules, safe URL handling, import limits, parent-reference validation, and publication guidance
